This module is a Drizzle Kit migration-only directory. The `meta/_journal.json` file tracks migration state (dialect: sqlite, version 7) and references the single migration entry `0000_better_auth_init`. The actual schema lives in `0000_better_auth_init.sql`, which creates four tables — `user`, `account`, `session`, and `verification` — with foreign key constraints from `account.user_id` and `session.user_id` to `user.id` using cascade delete. Unique indexes are defined on `session.token` and `user.email`. There are no TypeScript schema definitions here; this directory holds only the SQL migrations and Drizzle's internal metadata used to apply them against an SQLite database.
