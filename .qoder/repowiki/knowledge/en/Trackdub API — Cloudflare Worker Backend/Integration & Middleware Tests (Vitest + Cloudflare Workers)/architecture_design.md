Tests are organized as one file per concern under `test/`, all running inside the Cloudflare Workers Vitest pool (`cloudflare:test`). A global setup hook in `apply-migrations.ts` uses `beforeAll` to call `applyD1Migrations(env.DB, env.TEST_MIGRATIONS)` once per test run, giving every test a fresh D1 instance. Each test file imports the real `@/index` Hono app and constructs a `Bindings` object by casting `env` from `cloudflare:test`. End-to-end assertions are made via `app.request(path, init, bindings)`, while middleware-only scenarios (auth, error) spin up a minimal synthetic Hono app that wires only the relevant middleware plus `onError`. Type augmentation for the test environment lives in `env.d.ts`, which extends `Cloudflare.Env` with `TEST_MIGRATIONS: D1Migration[]` so tests compile without a prior `wrangler types` step.
