Tests run under the Cloudflare Workers Vitest pool, which requires the `@cloudflare/vitest-pool-workers` dependency and a `vitest.config.ts` that registers the workers pool. The global `beforeAll` in `apply-migrations.ts` must execute before any test that touches D1, and `env.d.ts` augments the global `Cloudflare.Env` type so `env.TEST_MIGRATIONS` is available without running `wrangler types` first.
