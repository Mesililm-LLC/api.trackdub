Migrations are generated by Drizzle Kit against the D1 database configured in `wrangler.activation*.jsonc` and written into `drizzle-activation/`. Tests run through `vitest.activation.config.ts`, which loads the same `drizzle-activation` migrations dir and injects them as `TEST_MIGRATIONS` binding; the test setup file `test/activation/apply-migrations.ts` applies them before each suite.
