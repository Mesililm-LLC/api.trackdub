Tests run under the Cloudflare Workers Vitest pool, requiring `@cloudflare/vitest-pool-workers` and a vitest config that registers the workers pool. The global `beforeAll` in `test/apply-migrations.ts` must execute before any test that touches D1, and `test/env.d.ts` augments the global `Cloudflare.Env` type so `env.TEST_MIGRATIONS` is available without running `wrangler types` first.
