The root is the project manifest and configuration hub that binds three child concerns together: the main app entry `src/index.ts` (declared in `wrangler.jsonc`) exposes a Hono server backed by Better Auth and Drizzle over D1; `drizzle.config.ts` generates SQL migrations into `./drizzle`, which both Wrangler (`migrations_dir`) and Vitest (`readD1Migrations`) consume so dev, deploy, and test all share one source of truth for schema. `vitest.config.ts` boots tests inside the real workerd runtime via `@cloudflare/vitest-pool-workers`, reusing bindings from `wrangler.jsonc` and injecting per-run migrations through `TEST_MIGRATIONS`. A second independent worker (activation) is wired through sibling configs (`wrangler.activation.jsonc`, `vitest.activation.config.ts`, `drizzle-activation.config.ts`) and exposed as separate npm scripts, keeping its D1 database (`trackdub_activation`) isolated from the main API. TypeScript path aliases (`@/* → ./src/*`) and shared types from `@cloudflare/workers-types` are declared once in `tsconfig.json` for all child modules.
