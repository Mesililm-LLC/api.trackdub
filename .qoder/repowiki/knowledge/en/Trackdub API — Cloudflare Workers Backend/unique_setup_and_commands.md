`npm run dev` boots the main worker locally; `npm run deploy` publishes it; `npm run db:generate` produces Drizzle migrations; `npm run db:migrate:local` / `db:migrate:remote` apply them to local or remote D1; `npm run cf-typegen` regenerates Worker type bindings; `npm run test` / `test:watch` run integration tests against an isolated workerd/D1 environment; parallel activation-worker commands (`dev:activation`, `deploy:activation`, `test:activation`, `db:migrate:activation:*`) target the separate `trackdub_activation` database.
